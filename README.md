# Академия продаж — LMS для менеджеров по недвижимости

Закрытая система обучения: курсы (текст + видео), тесты с проверкой, база знаний / скрипты продаж и админ-панель. Вход только по логину и паролю, которые выдаёт администратор — самостоятельная регистрация отключена.

**Как это устроено:** сайт (HTML/CSS/JS без сборки) размещается на GitHub Pages, а логины, пароли и все данные хранятся в [Supabase](https://supabase.com) — бесплатном облачном бэкенде с базой данных и системой авторизации. GitHub Pages сам по себе не умеет проверять пароли (это просто хостинг файлов), поэтому связка с Supabase обязательна для настоящей защиты.

---

## Что нужно сделать (по шагам)

### Шаг 1. Создайте проект Supabase
1. Зарегистрируйтесь на [supabase.com](https://supabase.com) (бесплатно).
2. New Project → задайте имя и пароль базы данных → дождитесь создания (1–2 минуты).

### Шаг 2. Создайте таблицы
1. В панели проекта откройте **SQL Editor → New query**.
2. Скопируйте туда весь файл [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**.
   Это создаст все таблицы (курсы, уроки, тесты, пользователи, база знаний) и настроит защиту доступа (RLS), чтобы менеджеры не могли редактировать чужие данные или назначать себе права администратора.

### Шаг 3. Отключите самостоятельную регистрацию
В Supabase: **Authentication → Sign In / Providers → Email** — выключите пункт, разрешающий пользователям самим регистрироваться (**Allow new users to sign up**). Аккаунты после этого можно будет создать только через админ-панель вашего сайта.

### Шаг 4. Разверните Edge Function для создания пользователей
Она нужна, чтобы кнопка «Создать аккаунт» в админке работала безопасно (пароль устанавливается на сервере Supabase, а не в браузере).

1. Установите Supabase CLI: `npm install -g supabase` (нужен Node.js).
2. В терминале, в папке проекта:
   ```
   supabase login
   supabase link --project-ref ВАШ-PROJECT-REF
   supabase functions deploy admin-create-user
   ```
   `PROJECT-REF` — это часть URL вашего проекта вида `https://XXXXX.supabase.co` (то, что вместо XXXXX).
3. Секретные ключи (`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`) Supabase передаёт функции автоматически — вручную ничего вписывать не нужно.

Если не хочется ставить CLI — то же самое можно сделать через веб-интерфейс: **Edge Functions → Create function** → назвать `admin-create-user` → вставить код из `supabase/functions/admin-create-user/index.ts`.

### Шаг 5. Создайте первого администратора
Пока в системе нет ни одного администратора, некому создать остальных. Сделайте первого вручную:
1. **Authentication → Users → Add user** — укажите email и пароль, поставьте галочку "Auto Confirm".
2. Скопируйте `UID` созданного пользователя.
3. **Table Editor → profiles → Insert row**: `id` = скопированный UID, `full_name` = ваше имя, `role` = `admin`.

Дальше всех остальных сотрудников (и других админов) можно создавать прямо из вашей админ-панели на сайте.

### Шаг 6. Впишите ключи проекта в сайт
Откройте `js/supabase-config.js` и замените:
```js
export const SUPABASE_URL = "https://ВАШ-ПРОЕКТ.supabase.co";
export const SUPABASE_ANON_KEY = "ВАШ-ANON-KEY";
```
Оба значения — в **Project Settings → API**. `anon key` — публичный ключ, его можно спокойно публиковать в открытом репозитории (не путайте с `service_role key` — тот не должен попасть на сайт никогда, он используется только внутри Edge Function на сервере).

### Шаг 7. Выложите на GitHub Pages
1. Создайте новый репозиторий на GitHub и загрузите туда все файлы этой папки.
2. **Settings → Pages → Source** → выберите ветку `main` и папку `/ (root)` → Save.
3. Через минуту сайт будет доступен по адресу вида `https://ваш-логин.github.io/название-репозитория/`.

Готово — заходите под созданным в шаге 5 админом и наполняйте систему через вкладки «Курсы и уроки», «Тесты», «База знаний».

## Структура файлов

```
index.html            — страница входа (логин/пароль)
dashboard.html         — курсы менеджера с прогрессом
course.html            — уроки одного курса + ссылка на тест
lesson.html            — текст + видео урока, кнопка "пройдено"
test.html               — прохождение теста
knowledge-base.html    — база знаний / скрипты продаж
admin.html              — админ-панель (пользователи, курсы, тесты, база знаний, прогресс)
css/style.css           — единая дизайн-система
js/                     — вся логика страниц
supabase/schema.sql     — структура базы данных и правила доступа
supabase/functions/     — серверная функция создания пользователей
```

## Как добавлять контент
Всё делается через вкладки в **Админке**, без кода:
- **Пользователи** — создание логина/пароля для менеджера или второго админа.
- **Курсы и уроки** — курс → внутри курса добавляете уроки (текст абзацами через пустую строку + необязательная ссылка на видео YouTube/Vimeo или файл .mp4).
- **Тесты** — привязывается к курсу, открывается менеджеру только после прохождения всех уроков курса; вопросы с вариантами ответов, отмечаете правильный.
- **База знаний** — статьи со скриптами продаж, группируются по категории.
- **Прогресс** — таблица результатов тестов по всем менеджерам.

## Ограничения, о которых стоит знать
- Это лёгкий клиентский LMS без отдельного сервера приложений: результаты тестов считаются в браузере пользователя и затем сохраняются в базу. Залогиненный сотрудник технически может через инструменты разработчика посмотреть, какой вариант ответа помечен как правильный (это ограничение архитектуры "статический сайт + Supabase" в принципе, а не баг). Для команды из доверенных сотрудников это не проблема; если нужна защита уровня "нельзя подсмотреть ответы даже через код" — тесты нужно будет проверять отдельной Edge Function на сервере (могу помочь дособрать при необходимости).
- Видео: система не хранит сами видеофайлы — вставляйте ссылку на YouTube/Vimeo (неопубличенные/по ссылке тоже подходят) или на .mp4, размещённый где-то ещё (например, в облаке).
- Бесплатный тариф Supabase отлично подходит для команды до нескольких сотен человек; трафик и объём базы ограничены, но для текстового контента и тестов этого хватит с большим запасом.


## Визуальный редактор материалов

В админке добавлен встроенный rich-text редактор без API-ключей и внешних библиотек. Он поддерживает жирный/курсив/подчёркивание, заголовки, списки, выравнивание, ссылки, изображения по URL и таблицы. Содержимое уроков и статей базы знаний сохраняется в существующее поле `content` как безопасный HTML, поэтому отдельная миграция схемы Supabase не требуется.

Для существующих уроков и статей доступна кнопка «Редактировать».
